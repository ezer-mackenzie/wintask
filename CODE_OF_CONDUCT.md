# Code of Conduct

## Our pledge

We want `wintask` to be a welcoming, respectful, and constructive project for
everyone. Contributors, maintainers, and users are expected to participate in
good faith and to treat one another with professionalism.

## Expected behavior

- Be respectful and considerate of different backgrounds and experiences.
- Give and receive technical feedback constructively.
- Focus on the issue, proposal, or code rather than the person.
- Prefer clear, inclusive language and explain assumptions when they matter.
- Respect project maintainers, reviewers, and community decisions.

## Unacceptable behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Trolling, deliberate disruption, or sustained bad-faith participation.
- Sexualized language or unwanted sexual attention.
- Publishing private information without explicit permission.
- Threats, abusive conduct, or other behavior that would be inappropriate in a
	professional technical community.

## Scope

This code applies in project spaces, including issues, pull requests, reviews,
discussions, and direct project communication when someone is representing
the project or its community.

## Reporting and enforcement

Please report unacceptable behavior privately to the project maintainers. Do
not create a public issue containing sensitive details. Include the relevant
links or messages, a description of what happened, and any context that can
help with a fair review.

Maintainers will review reports as promptly and confidentially as practical.
They may clarify expectations, request changes, remove content, restrict
participation, or take other action appropriate to the circumstances. Reports
will be handled respectfully and retaliation for a good-faith report is not
acceptable.

This code of conduct is adapted from the [Contributor Covenant][covenant],
version 2.1. The full text is available at:
